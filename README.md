# alu-shell

This repository contains simple shell scripts:

- basics/14-copy_html: Copies HTML files to parent if newer
- basics/15-lets_move: Moves files starting with uppercase to /tmp/u
- basics/16-clean_emacs: Deletes files ending with ~
- basics/17-tree: Creates welcome/to/school directories
- permissions/0-iam_betty: Switches current user to betty
