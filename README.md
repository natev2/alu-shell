# alu-shell

This repository contains simple shell scripts for learning basic Linux commands and permissions.

## Basics

- **14-copy_html**: Copies HTML files from the source directory to the destination directory.  
- **15-lets_move**: Moves files from one directory to another.  
- **16-clean_emacs**: Removes backup files created by Emacs (`*~`).  
- **17-tree**: Displays the folder structure of a directory in a tree-like format.  

## Permissions

- **0-iam_betty**: Switches the current user to `betty`.  
- **1-who_am_i**: Prints the current logged-in user.
