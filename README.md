# ALX Shell Scripts

This repository contains simple shell scripts for file and directory operations, as part of the ALX SE/Linux curriculum. All scripts are written in Bash, tested on Ubuntu 20.04 LTS, and follow the project constraints (exactly 2 lines, first line is #!/bin/bash, no backticks, &&, ||, or semicolons, and executable).

## Scripts

### 0-iam_betty
Switches the current user to betty.

### 14-copy_html
Copies all .html files from the current directory to the parent directory, but only if they do not exist there or are newer.

### 15-lets_move
Moves all files starting with an uppercase letter to /tmp/u.

### 16-clean_emacs
Deletes all files in the current directory that end with the ~ character.

### 17-tree
Creates the directories welcome/, welcome/to/, and welcome/to/school in the current directory.
